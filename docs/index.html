Local-first reminder app

One focus, next actions, quiet backlog.

Jaw Reminders is a Tauri and React prototype for agent-heavy CLI-JAW work. It keeps reminders local, separates waiting state from active work, and gives the current focus a dedicated rail.

Built for short, fragile follow-ups.

Capture inline

Each matrix quadrant owns its own add row, so triage and capture happen in the same place.

Keep one focus

The native mutation layer enforces a single focused reminder instead of allowing several competing priorities.

Separate waiting

Blocked reminders move out of the active lane without disappearing from the work context.

React handles interaction. Rust owns durable state.

Frontend

React 19, strict TypeScript, feature modules under src/features/reminders, and Vite for browser iteration.

Native

Tauri commands route reminder mutations to Rust for persistence, validation, and notification display.

Privacy

Browser fallback uses localStorage. Native mode writes a local JSON snapshot in the app data directory.

Verification surface.

Frontend

npm run typecheck, npm test, and npm run build.

Native

npm run tauri:check and npm run tauri:test.
